# n3ds-native (working name)

Experimental toolchain to run your own Nintendo 3DS games natively on iPhone and iPad, without an emulator, in the spirit of nxnative (which does the same for Switch).

**Status:** planning / skeleton. Nothing runs yet.

## Requirements (planned)

- Your own game dumps (.3ds / .cia / decrypted CCI) and your own keys, from your own console.
- A Mac with Apple Silicon and Xcode (for the build step).
- iOS/iPadOS target to be confirmed once the GPU layer is prototyped.

This project does not distribute games, dumps, keys, or firmware. Do not commit any of them.
